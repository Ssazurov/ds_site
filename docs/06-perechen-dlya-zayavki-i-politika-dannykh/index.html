2. Политика данных (кратко)

  • Обрабатываются: имя и возраст ребёнка (профиль), прогресс, настройки, PIN родителя.
  • Хранение: только на устройстве; нет сервера, аналитики, рекламы.
  • Передача третьим лицам и за пределы РФ: не осуществляется (152-ФЗ: оператор данные не получает).
  • Удаление: пользователем — удалением профиля/приложения.
  • Страницы сайта проекта: privacy, consent, terms, delete-data, disclaimer — поддерживать в соответствии с этим разделом.

3. Открытые вопросы к автору

  1. Правообладатель — физлицо (Сазуров С. В.); в реестре физлица допускаются — подтвердить способ подтверждения прав.
  2. Лицензионная модель (бесплатно/платно, текст лицензии).
  3. Хранение PIN: убедиться, что в виде хэша (иначе доработать).
  4. Минимальная версия Android — зафиксировать из реальной сборки.
  5. Скриншоты и иконка для RuStore (512×512).
  6. Аудио-покрытие 100 % (нужно и для Авроры).
