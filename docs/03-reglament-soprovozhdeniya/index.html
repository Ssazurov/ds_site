Регламент сопровождения — «Солнечный мир»

1. Общие положения

Регламент определяет порядок технической поддержки, исправления ошибок и выпуска обновлений ПО «Солнечный мир». Исполнитель — правообладатель (Сазуров С. В.). Сопровождение бесплатное для пользователей.

2. Каналы обращений

Почта sazurov@mail.ru (основной); Telegram @Sazurov; ВКонтакте vk.ru/sazurovsv; задачи — GitHub Ssazurov/ds_app (Issues). Обращение должно содержать: версию приложения («О разработчике»/«Лицензии»), модель устройства, версию ОС, описание и шаги воспроизведения.

4. Версионирование и выпуски

Версия MAJOR.MINOR.PATCH+BUILD (pubspec.yaml). PATCH — исправления, MINOR — новые функции/контент, MAJOR — несовместимые изменения. Плановые выпуски — по мере готовности, не реже 1 раза в квартал; хотфиксы — вне плана. Каждый выпуск сопровождается заметками (release notes) в GitHub Releases и в RuStore.

5. Процесс изменений

  1. Задача в GitHub Project (Backlog → In progress → Done).
  2. Ветка от main, Pull Request с Closes #N.
  3. Автоматические проверки: flutter analyze, flutter test.
  4. Слияние (squash), сборка релиза, подпись, публикация (Руководство по установке и обновлению).
  5. Проверка на тестовом устройстве (запуск, карточки, озвучка, профили, «Для родителей»).

6. Обновление контента

Контент (слова, картинки, озвучка, истории) собирается в пакет tools/build_pack.py и поставляется в составе обновления приложения. Проверка контента автором перед публикацией (ревью-инструмент).

7. Информационная безопасность

  • Приложение не передаёт данные в сеть и не содержит трекеров.
  • Зависимости проверяются при каждом выпуске (flutter pub outdated), критические уязвимости — приоритет P1.
  • Ключ подписи Android хранится вне репозитория, резервная копия — у правообладателя.
  • О найденных уязвимостях сообщать на sazurov@mail.ru; ответ в течение 2 рабочих дней.

8. Резервное копирование

Исходный код — GitHub (Ssazurov/ds_app, ds_words), локальная копия; контент-пакет и реестры — в репозитории ds_words. Данные пользователей приложение не собирает, поэтому резервирование на стороне разработчика не требуется.

9. Поддерживаемые версии и вывод из эксплуатации

Поддерживается последняя версия и предыдущая MINOR. Об окончании поддержки пользователи уведомляются в карточке RuStore не менее чем за 3 месяца. Исходные коды и документы хранятся не менее 5 лет.

10. Удаление данных

Запрос на удаление данных не требуется — данные хранятся только на устройстве (удаление приложения/данных в настройках ОС). Страница на сайте проекта: delete-data.
