Совместимость с ОС Аврора — анализ и план порта

Статус: текущая сборка не совместима «из коробки»; порт возможен (Flutter-приложение, чистый Dart + 5 плагинов).

1. Факты

  • Аврора использует собственный форк Flutter SDK (платформа Aurora не входит в upstream). В документации Авроры указан Flutter 3.35.7; проект собран на Flutter 3.47 / Dart ^3.13 → нужна отдельная ветка/сборка на SDK Авроры.
  • Приложение: Android-пакет ru.ds.ds_app; для Авроры нужен свой embedder, .spec/desktop-файл, RPM-пакет и подпись (ключи/сертификат разработчика Авроры).
  • Аврора не запускает APK без слоя совместимости; сборка — нативная (aurora-платформа Flutter, архитектуры aarch64/armv7hl/x86_64).

3. Что уже хорошо

  • Нет INTERNET/разрешений; хранение — SharedPreferences.
  • Озвучка/TTS вынесена за абстракцию Speaker/SequenceSpeaker (speaker.dart) — подмена реализации без правки экранов.
  • Контент в ассетах (pack/), оффлайн.

4. Блокеры

  1. Озвучка: без TTS нужны готовые аудиозаписи для всех 369 карточек и историй (сейчас в пакете озвучка частичная → fallback на flutter_tts). Условие порта: покрытие аудио 100 %.
  2. Версия Flutter SDK Авроры ниже проекта — возможна правка синтаксиса/зависимостей (понижение пакетов в отдельной ветке).
  3. Сертификаты и подпись RPM; тестовое устройство или эмулятор Авроры (SDK — Аврора IDE/Platform SDK).

5. План (задачи)

  1. Установить Flutter SDK Авроры + Platform SDK, flutter doctor (0,5 дня).
  2. Ветка aurora: flutter create --platforms=aurora ., понизить зависимости до совместимых (1 день).
  3. Реализовать AuroraSpeaker (только audioplayers), заглушки для package_info/file_picker (1 день).
  4. Довести аудио до 100 % покрытия (контент-задача ds_words#3).
  5. Сборка RPM, запуск на эмуляторе/устройстве, регресс по Руководству пользователя (1–2 дня).
  6. Публикация: RuStore (раздел для Авроры, при наличии) / Аврора Маркет; подпись RPM; дополнить разделом «Аврора»: Руководство пользователя, Описание функциональных и технических характеристик, Регламент сопровождения, Руководство по установке и обновлению.
