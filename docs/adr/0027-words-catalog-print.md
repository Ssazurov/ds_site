# ADR-0027: Каталог слов/карточек и печать в PDF

**Статус**: Принято
**Дата**: 2026-10-09
**Контекст**: ds_site#27, зависит от ds_words#1 (закрыт)

## Контекст

Нужен раздел сайта с каталогом слов из справочника ds_words: фильтры по
теме и возрасту, печать выбранного набора карточек для офлайн-занятий
(без устройства). Источник слов и картинок — ds_words (`dist/words.ru.json`,
`registry/images.json`); на момент реализации сгенерировано 184 картинки
из 1000 слов.

## Решение

- `scripts/export-words.mjs` — локальный скрипт (по аналогии с
  `export-content.mjs`, но без секретов): читает ds_words
  (`--words-dir`, по умолчанию `../../ds_words`), уменьшает картинки до
  480px/webp (`sharp`) и пишет `public/words/data.json` +
  `public/words/images/*.webp`. Результат **коммитится** в репозиторий
  (не секрет, не зависит от окружения деплоя — работает одинаково в
  standalone и в статическом экспорте, без ветвления `IS_STATIC`).
- `/words` — каталог: чипы тем, фильтр по возрасту (попадание в диапазон
  `age` слова), переключатель «только с картинкой», выбор карточек.
- `/words/print` — печатная раскладка A4 (3 колонки, `break-inside: avoid`),
  кнопка «Печать» вызывает `window.print()` — сохранение в PDF средствами
  браузера. Шапка/подвал/баннер согласия скрыты через `@media print`.

## Последствия

✅ Не требует серверной части — весь каталог статический, работает и в
standalone, и в GH Pages экспорте
✅ PDF получается стандартным диалогом печати браузера — без зависимостей
для генерации PDF на сервере
⚠️ Из 1000 слов картинки пока только у 184 — каталог по умолчанию
фильтрует «только с картинкой»; остальные появятся по мере генерации
(ds_words#12) без изменений в ds_site
⚠️ Скрипт не запускается автоматически при деплое — обновление каталога
требует ручного прогона и коммита (как и `export-content.mjs`)
