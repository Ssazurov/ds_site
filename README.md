# ds_site
Сайт для родителей детей с СД и специалистов: глоссарий, ссылки на ресурсы,
статьи + RAG-чат. Данные и поиск — через GAR API, свой контент не хранит.
Без встроенной админки: управление контентом (в т.ч. черновики новостей)
и публикация — в `ds_search/ui/` (Streamlit, см. ADR-003 доп. 2026-09-07).

Стек: Next.js + Tailwind (паттерн gar-admin-ui, независимый репозиторий).

См. `ds_search/docs/adr/ADR-004-produkt-1-sayt.md`.

## Запуск (dev)
```bash
cd /home/vector/projects/ds/ds_site && npm run dev -- -p 3001
```
Сайт: http://localhost:3001/ (требует запущенный gar-core-api, обычно порт 8100).

## Внешний сайт (GitHub Pages)
https://ssazurov.github.io/ds_site/ — статическая сборка, раздаётся ветка `gh-pages`
(GitHub Action не используется). Решение: `ds/docs/adr/0018-external-static-site.md`.

### Как обновить контент
- **Кнопка:** ds_search (Streamlit) → вкладка «Внешний сайт» → подтвердить → «Пересобрать».
- **Вручную (WSL):** `cd /home/vector/projects/ds/ds_site && npm run publish:pages`.
  Нужны: `.env.local` (`GAR_URL`, `GAR_PUBLIC_API_KEY`), запущенный gar-core-api,
  `gh auth login` с правом push. Опции скрипта: `--dry-run` (собрать и проверить без
  публикации; `npm run build:static` = `--skip-export --dry-run`), `--skip-export`
  (не ходить в GAR, взять готовый `data/export`).
- **Что попадает на сайт:** только источники с разрешением «не требуется» / «получено»
  (поле задаётся в ds_search → «Источники»). «Не выбрано» и «запрещено» отбрасываются
  при выгрузке, в логе — `отброшено {...}`. Полный текст — только при «получено»,
  иначе краткое содержание со ссылкой на источник.
- После первого запуска `git checkout -- tsconfig.json` (Next дописывает туда `.next-static/types`).

### Как проверить публикацию
- В конце лога: `проверка секретов: N файлов чисто` и `опубликовано: <URL>`.
- Время последней публикации: `git log origin/gh-pages -1` (сообщение `publish <время>`).
- Открыть сайт (Pages обновляется 1–2 мин, Ctrl+F5): статьи/новости на месте, есть
  ссылка на источник, страницы `noindex`. Если пусто — у источников не проставлено разрешение.

### Помощник: скрыть / показать
- **Внешний сайт:** флаг фиксируется при сборке — `NEXT_PUBLIC_ASSISTANT_ENABLED=1 npm run publish:pages`
  (по умолчанию `0`, скрыт). Пока переменная задана, `/settings` флаг не меняет.
- **Внутренний сайт:** `/settings` → «Показывать Помощника…»; там же URL внешнего GAR.
- Флаг также скрывает флажки выбора статей в карточках.

### Отозвать публикацию
Поставить источнику «запрещено»/«не выбрано» и пересобрать: `gh-pages` перезаписывается
(история не копится). Кэши и копии третьих лиц отозвать нельзя.
