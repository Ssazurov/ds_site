# Руководство по установке и обновлению (RuStore, APK) — «Солнечный мир»

## 1. Для пользователя

### 1.1. Установка из RuStore (рекомендуется)
1. Установите RuStore с rustore.ru (на устройствах, где он не предустановлен).
2. Откройте RuStore → поиск → «Солнечный мир».
3. Нажмите «Установить». Приложение появится в списке программ.

### 1.2. Установка из APK-файла
1. Скачайте файл `app-release.apk` с сайта проекта/по ссылке от разработчика.
2. Разрешите установку из этого источника (Настройки → Безопасность/Приложения → «Установка неизвестных приложений»).
3. Откройте файл и подтвердите установку.
4. Сверьте контрольную сумму SHA-256, опубликованную рядом с файлом: `sha256sum app-release.apk`.

### 1.3. Обновление
- RuStore: Мои приложения → Обновления → «Обновить» (или включите автообновление).
- APK: установить новый APK поверх старого (подпись должна совпадать; профили и прогресс сохраняются).

### 1.4. Удаление
Настройки ОС → Приложения → «Солнечный мир» → Удалить (локальные данные удаляются вместе с приложением).

## 2. Для разработчика: публикация в RuStore
1. Аккаунт в RuStore Консоль (console.rustore.ru): регистрация правообладателя (физлицо/ИП/юрлицо), подтверждение данных.
2. Сборка релиза:
   `cd app && ~/flutter/bin/flutter build apk --release --no-pub` (или `appbundle`).
   Результат: `app/build/app/outputs/flutter-apk/app-release.apk`.
3. Подпись: release-keystore (не коммитить). Версия — только вверх: увеличить `version: X.Y.Z+BUILD` в pubspec.yaml (BUILD = versionCode).
4. В Консоли: «Создать приложение» → загрузить APK/AAB → заполнить карточку:
   - название, краткое и полное описание (из док. 01–02);
   - категория «Образование»/«Дети», возрастной рейтинг (0+);
   - иконка 512×512, 4–8 скриншотов, (опц.) видео;
   - ссылка на политику конфиденциальности (сайт: /privacy), контакты поддержки;
   - сведения о правообладателе, лицензия.
5. Отправить на модерацию (обычно 1–3 рабочих дня) → публикация.
6. Обновление: «Новая версия» → загрузить APK с большим versionCode → release notes → модерация.

## 3. Проверка перед публикацией
- [ ] `flutter analyze` и `flutter test` без ошибок.
- [ ] Release-APK установлен на чистое устройство: запуск, профиль, карточка со звуком, игра, «Для родителей».
- [ ] Разрешений в манифесте нет (`aapt dump permissions app-release.apk`).
- [ ] Версия и release notes совпадают с GitHub Release.
- [ ] Опубликованы SHA-256 и ссылка на APK (если распространяется вне RuStore).

## 4. Откат
Опубликовать исправленную версию с большим versionCode; предыдущую версию из выдачи снять в Консоли. Понижение versionCode невозможно.
